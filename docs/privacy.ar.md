# الخصوصية والتعامل مع البيانات

[English](privacy.md) · [البداية](../README.ar.md)

## ماذا في المستودع؟

تعليمات Markdown قابلة لإعادة الاستخدام، وقوالب فارغة باللغتين، وبيانات المهارة، ومثال مخترع بوضوح، ومواد مشاركة عامة. لا يضم موجزات مشاريع حقيقية أو بيانات عملاء أو مسارات أجهزة أو مفاتيح أو حسابات. أدوات التصميم الاختيارية روابط وليست برامج معاد توزيعها.

## ماذا يقرأ المساعد؟

تعريف المنتج والموقع الحالي وقواعد المشروع والملفات اللازمة للمهمة التي طلبتها. أنت تحدد المشروع والنطاق. احذف الأسرار وبيانات العملاء والعمل غير المرتبط قبل تسليم الموجز لأداة خارجية. أبقِ البحث الخاص وأدلة المراجعة خارج تاريخ Git العام.

## أين قد تذهب البيانات؟

المساعد والنموذج يعالجان السياق وفق إعدادات مزوّدهما. تصفح المصادر العامة يستخدم خدمة المتصفح أو البحث. أداة مثل Lovable تستقبل الموجز والأصول التي تنقلها إليها فعلًا. قد يستخدم التنفيذ خدمات المشروع الموجودة؛ فرع المعاينة لا يثبت وجود قاعدة بيانات معزولة. لا ندّعي أن معالجة النموذج محلية أو دون اتصال.

لا تضم المهارة تتبعًا أو برنامجًا تنفيذيًا أو مثبّتًا أو مراقبًا في الخلفية. تنزيل المجلد لا يربط الاستضافة أو ينشئ حسابات أو ينشر موقعًا أو يضيف تحليلات.

## النماذج والاختبارات والنشر

حدّد وجهة البيانات الحقيقية قبل اختبار الإرسال. استخدم بيانات اختبار مسموحًا بها واحفظ سجلات العملاء الفعلية. اعتماد الموجز لا يسمح وحده بإرسال رسائل أو استخدام خدمات مدفوعة أو ربط حسابات أو نشر موقع. robots وnoindex لا يحميان البيانات؛ يلزم التحكم الحقيقي في الوصول.

مقطع الصيانة يجعل اتساق الموقع جزءًا من تعديلات المستودع المعتمدة، ولا ينشئ إذن نشر تلقائيًا أو موعدًا متكررًا.

## عند مشاركة نسختك

صدّر الملفات القابلة لإعادة الاستخدام التي راجعتها عمدًا فقط. استبعد الموجزات المعبأة بمعلومات خاصة والملفات الشخصية والمحادثات والصور الخاصة وملفات البيئة والمفاتيح والتاريخ غير المرتبط. افحص محتوى الصور وبياناتها الوصفية مع النصوص. استخدم أمثلة مخترعة في البلاغات العامة.
